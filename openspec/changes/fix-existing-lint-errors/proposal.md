# Proposal

## Why

升级后的 ESLint 在当前代码中报告 119 个错误和 532 个警告。部分错误涉及子组件修改父级数据、通知链接内容和列表渲染；清理这些问题可以恢复可用的 lint 检查，同时保持论坛现有交互。

## What Changes

- 将点赞、关注、订阅和分页的数据更新交还给拥有数据的组件，并连通现有调用方。
- 保留通知链接中的 HTML 内容及用户动态的过滤逻辑，修复不符合 Vue 组件语义的写法。
- 清理未使用的组件与变量、分号、重复全局声明、不安全的自有属性检查、switch 作用域及多余异常包装。
- 使用现有 ESLint 规则验收零错误，记录剩余警告；不批量整理警告、不升级依赖、不重构业务架构。

## Capabilities

### New Capabilities

- `forum-ui-consistency`: 记录本次修复所需的关系操作、分页、通知与动态列表的交互约束及 lint 验收要求。

### Modified Capabilities

无。当前仓库尚无正式规格。

## Impact

涉及 `src/components/`、相关论坛页面、HTTP 拦截器及初始化代码。复用现有 API 路径和请求结构；粉丝及关注列表通过已有分页接口加载用户选择的页码。保留 Vue 2 Options API，不修改环境配置、认证信息或 ESLint 规则。验证包括 lint、生产构建、针对状态流的组件回归检查，以及本地浏览器页面检查；有副作用的关系操作使用拦截的测试响应，不向线上账号写入数据。
