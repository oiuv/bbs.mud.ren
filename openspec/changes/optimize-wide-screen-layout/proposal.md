# Proposal

## Why

论坛容器在大屏仍限制为 1190px。1920×1080 实测左右各空出 365px，14px 帖子标题也显得偏小，未充分利用桌面空间。

## What Changes

- 宽屏容器随窗口增长，上限 1680px，导航、内容与页脚保持一致。
- 首页、版块帖子和用户帖子列表扩大主栏，侧栏保持适中宽度；放大宽屏列表标题、头像和留白。
- 帖子详情正文保留可读行长，嵌套容器不重复缩窄。
- 保留深浅主题、手机和平板布局、现有导航与业务行为。

## Capabilities

### New Capabilities

- `responsive-forum-layout`: 宽屏空间利用、主侧栏比例、阅读宽度和窄屏兼容。

### Modified Capabilities

无。

## Impact

全局 Sass 布局和相关页面的布局类名。无 API、依赖、路由或数据变更。以真实首页及桌面/手机截图、尺寸测量、lint 和生产构建验收。
