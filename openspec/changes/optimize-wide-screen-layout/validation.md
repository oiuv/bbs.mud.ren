# 宽屏布局验收

日期：2026-09-20。本机开发服务 http://127.0.0.1:8081/，Edge 隔离会话，浏览器缩放 100%。

## 实测结果

| 1920×1080 下的项目 | 调整前 | 调整后 |
| --- | --- | --- |
| 页面容器 | 1190px | 1680px |
| 左右外边距 | 各 365px | 各 120px |
| 首页主栏（含左右内边距） | 892.5px | 1330px |
| 首页侧栏（含左右内边距） | 297.5px | 350px |
| 帖子标题 | 14px | 16px |

宽屏侧栏内容为 320px，正文内容块上限 1040px，编辑器列上限 1200px。横幅链接随容器扩展，修复原始图片宽度不足时右侧留空的问题；素材保持原样。

## 验证

- 首页测量 1920、2560、1440、1366、1280、768、390、320px：均无页面横向溢出。2560px 下容器仍为 1680px；1280px 下仍为原来的 1190px。
- 1920px 检查版块列表、单版块、公开个人主页、搜索、登录、注册和帖子详情：容器宽度符合规则，嵌套容器未溢出。
- 1366、1440、1920px 下的帖子悬浮操作均在可见区域，且未遮挡主栏。超长无空格标题和八位数统计的临时响应样例未重叠或造成溢出。
- 复用主题浏览器验收脚本，在临时副本中将桌面视口改为 1920×1080，并添加编辑器宽度和横幅铺满断言：59 项通过。覆盖两种主题、键盘切换、刷新恢复、模拟登录成功/失败、编辑器草稿保持、弹窗和移动导航；2 次登录写请求均被拦截，没有真实 API 写请求。
- 已人工查看深浅首页、1440px 首页、390px 手机、帖子详情和编辑器截图。模拟账号仅存在于已关闭的隔离浏览器会话。
- `npm run lint:check` 通过，0 错误、0 警告。
- 最终 `npm run build` 通过，hash `1191fc52e8cbd703`。保留原有样式模块默认导出和包体积警告。
- `openspec validate optimize-wide-screen-layout --strict` 通过。
