# Proposal

## Why

前一轮修复后 lint 已无错误，但仍有 530 个警告，掩盖了新增问题。其中 9 个涉及原始 HTML 渲染，需要在保留论坛内容展示的同时明确清理边界。

## What Changes

- 按现有规则整理模板格式、属性顺序、组件选项顺序和组件名称。
- 将两个分页省略号改为静态文本；正文、通知及搜索高亮统一通过 HTML 清理组件显示，保留常用排版和链接，过滤脚本、事件属性及危险 URL。
- 将用户媒体与用户列表项实际必需的 `user` prop 标记为必填。
- 维持 ESLint 规则与检查范围，达到零错误、零警告，完成回归、构建和浏览器验证后单独提交。

## Capabilities

### New Capabilities

- `safe-rich-content`: 正文、通知和搜索高亮在显示前经过 HTML 清理，保留安全的内容格式与链接。

### Modified Capabilities

无。正式规格目录当前为空；此前 `forum-ui-consistency` 变更继续保留，其关系操作及分页约束沿用。

## Impact

涉及现有 Vue 单文件组件、通用 HTML 渲染组件和回归脚本。新增 DOMPurify 运行依赖及相应锁文件条目，不变更 API、环境配置或认证流程，不调整 Sass 构建警告。活动脚本、危险链接和非内容类嵌入不再作为原始 HTML 注入页面；正常的标题、图片、代码块、通知正文和搜索高亮需要回归确认。
