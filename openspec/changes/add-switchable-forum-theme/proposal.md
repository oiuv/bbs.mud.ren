# Proposal

## Why

论坛目前只有浅色外观，与 mud.ren 主站的近黑、暖橙和米白视觉不一致。默认采用主站风格，同时让习惯浅色的用户保留阅读选择。

## What Changes

- 默认深色主题，采用主站公开 CSS 的背景、表面、文字、强调色和边框色。
- 提供桌面和手机均可使用的深浅主题按钮，游客和登录用户均可切换；在本浏览器保存选择。
- 首屏按保存的主题显示；存储不可用时仍能切换，跨标签页同步有效选择。
- 统一导航、列表、正文、版块、资料、搜索、认证表单、编辑器、通知和弹窗的主题颜色，保留现有业务结构。

## Capabilities

### New Capabilities

- `forum-theme`: 默认深色、可切换和持久化的论坛主题，以及通用界面的颜色适配。

### Modified Capabilities

无。

## Impact

涉及 public 首屏初始化、Vue 主题状态和按钮、全局 Sass 及少量硬编码组件样式。不修改后端、API、账号设置或业务流程，不新增依赖。Dify 等外部 iframe 的内部主题由外部服务控制。
